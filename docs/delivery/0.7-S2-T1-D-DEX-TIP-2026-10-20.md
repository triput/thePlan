## Scope

Microsoft Graph **`showAs`** → stored transparency / provenance / effective free-busy kind, wired through Microsoft calendar upsert into **BusyInputTrust** collect semantics. Complements [T1-C tip](0.7-S2-T1-C-DEX-TIP-2026-10-20.md) (freshness @ **`9a6228a`**); does **not** verify live Microsoft calendar freshness or end-to-end scheduling against production Graph.

**Design (Jim-acked residual):** incomplete-update **handler**, not a pure complete-payload guarantee. **Option B (residual close):** carry **fetch-context evidence** through list/view/delta apply into upsert; derive showAs completeness from **parseable bounds AND established representation context** — not `times_ok` alone and **not** inferred from a missing `showAs` key.

| Case | Behavior |
| --- | --- |
| Existing row with known bounds + partial `{id, showAs: …}` without start/end | Preserve bounds; apply `showAs` when present |
| Same shape, omitted `showAs` | `unknown_projection` — must **not** leave trusted free |
| Established list/view/delta context + parseable times + omitted `showAs` | `unknown_missing` (fail closed — not placement escape) |
| Projected `$select` (no `showAs`) + parseable times + omitted `showAs` | `unknown_projection` — demotes previously trusted free |
| Upsert with no fetch context + omitted `showAs` | Explicit uncertainty → `unknown_projection` |
| `complete_representation` (resolver) | `times_ok` **and** `show_as_representation_established`; projected → `field_projected` |

Both **`unknown_projection`** and **`unknown_missing`** already fail closed on BusyInputTrust — this slice is **provenance/completeness hardening**, not a new “unknown means free” escape hatch.
