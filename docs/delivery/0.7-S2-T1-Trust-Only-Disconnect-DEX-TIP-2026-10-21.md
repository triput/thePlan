## Implementation Plan §II.4 — FK / cascade inventory (disconnect slice)

Inspected ORM + Alembic models for rows touched by **`disconnect_calendar_account`** (bulk event delete + account delete). Disconnect does **not** call remote calendar APIs.

| Child / related | FK → `calendar_accounts` / events | ON DELETE | Disconnect effect |
| --- | --- | --- | --- |
| `calendar_subscriptions` | `calendar_account_id` | **CASCADE** | Removed with account (ORM cascade on account delete) |
| `calendar_subscription_refresh_failures` | `subscription_id` → subscriptions | **CASCADE** | Sidecar removed with subscription |
| `external_calendar_events` | `calendar_account_id` | **CASCADE** | Bulk-deleted in route **before** account delete |
| `external_calendar_events.task_id` | → `tasks` | **SET NULL** | Task rows **retained**; link cleared if event deleted |
| `external_calendar_events.scheduled_block_id` | → `scheduled_blocks` | **SET NULL** | Block rows **retained**; link cleared if event deleted |
| `scheduled_blocks`, `tasks`, settings, availability, focus windows, free/busy policy tables | owner-scoped; no FK to account | — | **Retained** (E8 snapshot) |
