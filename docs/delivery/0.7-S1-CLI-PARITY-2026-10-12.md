## Scope stamped (this vertical)

HTTP CLI wrappers for S1 foundations already on the API:

| Surface | CLI |
| --- | --- |
| User settings | `settings get`, `settings patch` |
| Availability policies | `availability list`, `get`, `patch`, `effective` |
| Task progress | `tasks progress add` |
| Remaining estimate | `tasks patch --remaining-estimate-minutes` + required `--expected-revision` |
| Scheduling-effective read | `tasks scheduling-effective --id`, `schedule effective --task-id` |

**Behavioral boundary (S1):** Working and General availability saves are **config-only** (`scheduling_effective: false`). Placement still follows legacy Time Maps and workweek/workday settings per [0.7-S1-LEGACY-TIME-MAP-COMPAT.md](0.7-S1-LEGACY-TIME-MAP-COMPAT.md). No focus-window / Time Map CRUD in this slice — DEF-040 stays Open.
