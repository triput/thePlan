### Readiness policy (structured)

- **`Invoke-DisposableHttpCheckWithReadiness`** polls when the probe observation classifies **`transport_fail`** (`Test-DisposableHttpTransportRetryable`). **No** dependency on expanding **`Test-DisposableHttpTransportNotReady`** prose (that helper remains for reachability tests only).
- **Terminal (no retry):** `http_status_mismatch`, `http_body_mismatch`, `http_error`, and other mapped **mismatches**.
- **`Invoke-HttpJsonCapture`** records **`web_exception_status`** when a **`WebException`** has no response; retryable statuses (secondary gate): ConnectFailure, ConnectionClosed, ReceiveFailure, SendFailure, Timeout, NameResolutionFailure, ProxyNameResolutionFailure, KeepAliveFailure.
- **Per-attempt budget:** each probe **`TimeoutSec`** and poll sleep clamp to **remaining time** before **`HttpDeadlineUtc`**.
- **Deadline expiry:** **`Throw-DisposableHttpCheckFailed`** with the **last transport_fail observation** attached — not a bare string throw that drops **`$Exception.Data`**.

### Null-body integrity

**`New-DisposableHttpEndpointObservationEntry`** must not cast `$null` body to `""` before hashing; transport failures with no HTTP body keep **`body=null`** and **`body_full_sha256=null`**.

**Evidence artifact:** `http-endpoint-observations.json` — same shape as val-3; partial write on fail before cleanup.
