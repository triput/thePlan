## Production paths touched

- **Resolve:** `POST /api/v1/calendar/resolve-series-policy` — advisory lock → reload trigger (`FOR UPDATE` + `populate_existing`) → lock sorted pending rows → policy/decision/baseline writes → clear pending on locked rows. `conflict_revision` includes `source_zone_untrusted`; stale ⇒ `409 FREE_BUSY_CONFLICT_STALE`; identity drift ⇒ `409 FREE_BUSY_IDENTITY_DRIFT`.
- **Diagnostics:** `GET /api/v1/calendar/busy-input-trust` — pending enrichment even when no policy row yet (`conflict_revision` + `current_provider_evidence.source_zone_untrusted`).
- **Collect / merge:** `collect_inputs` + `busy_from_sources` / `build_busy_map` — request-scoped `policy_map` (no module dict in production).
- **Google ingest:** `_upsert_external_event` — sorted advisory locks (old+new identity on drift) → reload row under lock → reject concurrent identity change → occupancy compare (Q1 T4 before raw kind mismatch) / T0b latch / automatic baseline seed.

Identity advisory namespace: **`1886415953`** (deterministic SHA256 key per four-tuple).

### Real concurrent DB sessions

Two `SessionLocal` connections. Resolve flushes and **does not commit** until `pg_locks` shows a **new ungranted** advisory waiter on namespace `1886415953` whose query is `pg_advisory_xact_lock`. Ingest is blocked in that lock. Final rows alone are not the concurrency proof.

Ordering is **resolve holds the lock first** (deterministic). Ingest-wins **stale revision** is covered separately (sequential commit order).

| Case | Test | Coherent outcome asserted |
| --- | --- | --- |
| Sibling race | `test_real_concurrent_sibling_race` | One policy, one decision. A pending cleared only after commit. B stays pending, latch retained, B's transparency write is invisible until the lock releases. |
| First-policy race | `test_real_concurrent_first_policy_race` | No policy row visible to other sessions during the hold. After both commit: exactly one policy, one decision, A cleared, B still pending. |
| New-instance race | `test_real_concurrent_new_instance_race` | C is not visible during the hold. After commit, C has an **automatic** baseline (policy was visible; not a manual decision). |
