## Dex evidence gap (2026-10-20) — outer refresh rollback

`test_google_apply_post_lock_identity_drift_fails_refresh_without_cursor_credit` calls `_apply_subscription_incremental` with only the failing event, then `expire_all` on that same transaction. It shows that event and the cursor unchanged. It does not show an earlier successful upsert rolling back, and it does not call `sync_account_events`.

`test_google_outer_refresh_rolls_back_prior_upsert_on_post_lock_drift` (parameterized `full` and `incremental`) uses mocked `list_calendar_events` / `list_calendar_events_incremental`. No live provider.

1. Event A upserts inside the refresh savepoint. On that Session, A is already `transparent` before event B runs.
2. Event B raises `GoogleUpsertPostLockIdentityDriftError` from a stale pre-lock identity snapshot (first `identity_key_from_row` call for B only).
3. `sync_account_events` rolls back the apply savepoint and the refresh savepoint, then commits failure trust on an autonomous session (`google_apply_full_failed` or `google_apply_incremental_failed`).
4. A **new** `SessionLocal` sees A and B still `opaque`, `sync_cursor` at its pre-refresh value (`null` for full, the prior token for incremental), coverage success and window cleared, and freshness trust not ok with that cause.
5. Another **new** `SessionLocal` replays both events without the stale snapshot and commits. A and B are `transparent`, the cursor is the replay token, failure cause is cleared, and trust is ok.

The autonomous failure marker clears coverage success and the coverage window and does not clear `sync_cursor`. The replay transaction therefore sees a missing window, invalidates with `coverage_horizon_widened` (that step clears the cursor), and pulls the **full** list for both parameters. That is the production recovery path.

Concurrent ingest replay is a different shape. `test_real_concurrent_google_post_lock_identity_drift_replays_ingest` calls `rollback` on the ingest `Session` and continues; it does not open a second `SessionLocal` for the replay.

No production defect. Evidence only.
