## Scope

Track-1 **T1-10 Alias canonicalize:** one enabled subscription row per canonical calendar identity per account; soft-disable alias rows (no hard-delete); sidecar refresh-failure row at most one per subscription with latest blocking failure carried forward; merge and subscription-key rewrite invalidate coverage; conflicting subscription PUT rejected atomically; event `calendar_id` rewrite for ingest consumers (not display-only). Wired through **`PUT /calendar/subscriptions`**, Google/Microsoft **`ensure_primary`** paths, and **pre-sync** `prepare_subscriptions_for_sync`. Complements [T1-C](0.7-S2-T1-C-DEX-TIP-2026-10-20.md) (failure sidecar), [T1-D](0.7-S2-T1-D-DEX-TIP-2026-10-20.md) (`showAs` trust), [T1-E](0.7-S2-T1-E-DEX-TIP-2026-10-20.md) (MS full-window mint). Does **not** verify live Graph id stability or authorize shipping.
