| URI | Expect | Content |
| --- | --- | --- |
| `http://127.0.0.1:18000/api/v1/auth/me` | **401** | JSON `code` **SETUP_REQUIRED** |
| `http://127.0.0.1:18080/` | **200** | body contains `<title>thePlan</title>` |
| `http://127.0.0.1:18080/api/v1/auth/me` | **401** | JSON `code` **SETUP_REQUIRED** (web proxy hop) |

Threaded through `Invoke-DisposableHttpCheckWithReadiness`, default probe **`Invoke-DisposableStartupHttpProbeCore`** → classify → **`Throw-DisposableHttpCheckFailed`** when not `http_ok` (structured observation attached on `$Exception.Data` before throw; no re-probe, no exception-string inference). Orchestration-only stubs live in **`New-TestDisposableSyntheticHttpEndpointObservation`** (test file only). Optional `HttpChecker` / `HttpProbe` scriptblock param **`[string]$ExpectJsonCode=""`**.

**Dex HOLD `1793640932` (prep):** failure path writes the **same** structured row that triggered the throw; missing `parsed_code` / body stay **null**; `got=<missing>` is not upgraded to UNAUTHENTICATED.

**Evidence artifact:** after all three probes (or on fail before cleanup), write **`http-endpoint-observations.json`** under the attempt evidence dir — one row per required URI with `expected_status` / `http_status`, bounded `body` + `body_full_sha256` when truncated, `parsed_code`, `classification` (`http_ok` | `mismatches` | `transport_fail` | `http_error`), acquisition fields, expectations, `observed_utc`. **`validation.candidate.json` / `validation.receipt.json`** carry `http_endpoint_observations: { path, sha256 }`; failure receipts reference the artifact when present.
