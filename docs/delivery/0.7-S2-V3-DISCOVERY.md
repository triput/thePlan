## 1. Goal (V3 only)

Make the **scheduler** treat **Working** and **General** availability policies as scheduling-effective: stop using deprecated **`workweek_*` / placement `workday_*`** mirrors for eligibility; wire **unclassified** tasks to the **General** link; keep **legacy Time Map** semantics for **unconverted** mapped tasks, clipped to **Working** (not General); honor **saved/active divergence** at activation; align **split / overnight / DST** window math with SPEC; ship **fingerprint / stale protection** for this activation (**S2-P3**). Flip **`scheduling_effective: true`** on policies the placer consumes.

S2-V3 is **engine cutover**, not Settings chrome (**S3**).

## 5. Saved/active divergence (A11a) — exercise requirements

S1 **deliberately** allows config that does not match the legacy placer ([S0 §0.3](0.7-S0-MIGRATION-CONTRACT.md#03-general--working--config-vs-scheduling-effective)). V3 must **activate** stored policies, not assume seeds stayed aligned.

### Minimum scenario matrix (Discovery — expand in Quality)

| Setup | Pre-V3 placer behavior | Post-V3 required behavior |
| --- | --- | --- |
| **Working divergence** | Legacy **`workweek_*`** active (`placer_active: true` on effective read); saved Working differs (e.g. **Mon–Wed 10:00–16:00** legacy vs **Mon–Fri 11:00–15:00** saved, or **Tue–Sat** saved with untouched mirrors) | After activation: **saved Working** drives global clip; effective read marks saved Working **`scheduling_effective: true`**; legacy mirror labeled inactive; previews pre-activation **stale** |
| **General divergence** | Unclassified uses **`workweek_*`**, not General rows | After activation: unclassified uses **General** link windows; General policy **`scheduling_effective: true`** |
| **Mapped + divergence** | Map semantics ∩ legacy workday clip | Map semantics ∩ **Working** saved windows; General edit still does not move mapped task |
| **Blocks** | N/A | No automatic block moves on activation alone |

### API / read-model signals (already partially implemented — extend at V3)

- Effective read: **`working_hours_active`** vs **`working_policy_saved`**, **`diverges_from_legacy`**, **`placer_active`** ([`test_s1_effective_provenance.py`](../../apps/api/tests/test_s1_effective_provenance.py) `test_a5_working_divergence_shows_both`).
- Post-V3: flip **`placer_active`** / **`scheduling_effective`** on the policy that the placer consumes; document activation in preview staleness (**`scheduling_activation`** token).

### Operator / activation messaging

- Show **which stored Working/General configuration becomes effective** at cutover (UI copy may lag **S3**; API + CLI must be honest).
- **Invalidate** older previews via revision + activation token; do **not** rewrite historical explanation JSON.
