## 1. Goal (V3 only)

Make the **scheduler** treat **Working** and **General** availability policies as scheduling-effective: stop using deprecated **`workweek_*` / placement `workday_*`** mirrors for eligibility; wire **unclassified** tasks to the **General** link; keep **legacy Time Map** semantics for **unconverted** mapped tasks, clipped to **Working** (not General); honor **saved/active divergence** at activation; align **split / overnight / DST** window math with SPEC; ship **fingerprint / stale protection** for this activation (**S2-P3**). Flip **`scheduling_effective: true`** on policies the placer consumes.

S2-V3 is **engine cutover**, not Settings chrome (**S3**).
